# developer.tylerakin.com

Modernized React single-page application for developer.tylerakin.com.

## Getting Started

```bash
yarn install
yarn start
```

The app runs at http://localhost:3000 by default.

## Available Scripts

- `yarn start` – start the local development server
- `yarn test` – run unit tests in watch mode
- `yarn build` – create a production build

## Tech Stack

- React 18 with React Router 6
- Framer Motion for lightweight motion design
- Testing Library + Jest for unit tests
